## При инциденте

| Ситуация | Немедленно | В течение дня | Подтверждение закрытия |
|---|---|---|---|
| ПДн или секрет ушли во внешнюю LLM или в трекер | Остановить запуски с `--drafter llm`; удалить задачу/комментарий; сообщить ИБ | Отозвать скомпрометированный токен или пароль; добавить шаблон в `masking.py` + тест с этим случаем | Тест с новым шаблоном проходит; ИБ подтвердила |
| Токен трекера попал в git или чат | Отозвать токен у владельца трекера | Удалить из истории (`git filter-repo`), выпустить новый токен в переменную окружения | `git log -p | grep` по старому токену — пусто |
| Опубликованы дубли или ошибочные задачи | Закрыть лишние задачи с пометкой | Найти причину по decisions.json (`by`, `at`, `replaces`) | Повтор сценария в тесте |
| Реальный дефект помечен как дубль или окружение и потерян | Завести баг вручную | Разобрать кандидата и оценку; поправить порог или шаблон окружения + тест | Метрика «approve без правок» не упала |
| Агент разработки обратился к рабочей системе или реальным данным | Остановить сессию агента | Проверить diff и историю команд; уточнить AGENTS.md | Ревью diff по скиллу без замечаний Blocker |
